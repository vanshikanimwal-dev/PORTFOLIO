## What the README describes

CertiChain issues a digital certificate and lets anyone check it from a public link. The certificate file stays off-chain. An SHA-256 fingerprint is the value that can be anchored later. The README is explicit that records in the project are synthetic, not real academic credentials.

The admin console and the public verification page talk to a Spring Boot API. That API uses PostgreSQL and MinIO, and it can register the fingerprint on a local chain or on Sepolia.

## Shape of the system

```text
web -> Spring Boot API
api -> PostgreSQL
api -> MinIO
api -> local chain or Sepolia
```
